How this tracker works

Everything is saved in this browser's localStorage under one key. Clearing site data or switching browsers loses it, so press Export JSON every Sunday and keep the file in your GitHub repo. Import JSON restores it. The Exam week toggle replaces that week's tasks with the exam minimum; nothing else shifts, the buffer weeks absorb it. The streak counts calendar days on which you pressed "I did my 1 problem today" or logged a problem.
